# Pro 결과물 품질·원가 점검표

## 실행 순서

1. `npm run evals -- --scenario <id>`로 해당 시나리오의 실제 분석 결과를 만듭니다.
2. `npm run evals:artifacts -- --scenario <id>`로 추천 안의 가이드·5축 평가·Bicep을 순서대로 생성합니다.

실제 실행에는 `.env.local`의 `ANTHROPIC_API_KEY`, `CLAUDE_MODEL`이 필요합니다. 결과는 `evals/results/<실행 시각>-artifacts/`에 저장됩니다. 결과 폴더는 모델 호출 전에 만들며, 같은 시각의 폴더가 이미 있으면 `<실행 시각>-2-artifacts/`처럼 번호가 붙습니다. 비용 상한 판단 자료이므로 종류별 평균 비용을 기록합니다.

## 확인 항목

- **두 언어**: `en`과 `ko`가 같은 내용인가 확인합니다. 한쪽에만 있는 설명이 없어야 하며, Bicep 코드의 주석과 `@description()`은 영어여야 합니다.

- **Bicep**: 저장된 `.bicep` 파일에 `az bicep build --file <파일>`을 사람이 직접 실행하고 컴파일 오류와 경고를 기록합니다. 자동화하지 않습니다(ADR-007). 구성 서비스와 리소스 종류·SKU·수량이 분석 결과와 맞는지 확인합니다.
- **가이드**: 단계를 순서대로 따라갈 수 있는지, 선택 안의 구성 서비스를 빠짐없이 다루는지 확인합니다.
- **평가**: 각 등급의 근거가 실제 구성 사실과 맞는지, 카탈로그 밖 서비스를 권하지 않는지 확인합니다.
- **원가**: 보고서의 종류별 평균 비용을 기록하고 Pro 결과물 생성 횟수 상한 결정 자료로 사용합니다(PRD 미확정 사항).
